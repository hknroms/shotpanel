ShotPanel

Turbo fire and button mapping for pads and arcade sticks, made for MAMEUI (Windows 10/11). It reads your controller, applies turbo and button swaps, and sends the result to MAMEUI as keyboard input. MAMEUI (mameui.exe) only. No installation needed. The app's screens are in Japanese.

How to use

Getting started

  1. Unzip, put the folder anywhere you like and run ShotPanel.exe. The first time, Windows may show "Windows protected your PC"; choose "More info" → "Run anyway". Settings are saved automatically to shotpanel.json in the same folder.
  2. Follow はじめにやること (Getting started) at the top of the window. Choose your MAMEUI folder (where mameui.exe is) with the browse button, close MAMEUI completely, then press the set-up button. It edits mame.ini next to mameui.exe (creating it if needed) and MAMEUI's input assignments (cfg\default.cfg: buttons and lever keyboard-only). MAME still sees the controller, so games with analog controls keep working. The original files are kept and can be restored.
  3. To change keys, use キーボードの設定 (Keyboard settings) and press the write button.
  4. Connected controllers appear automatically. Set each one to 1P, 2P or Off. If the buttons on screen are not where the real ones are, register their positions by pressing them.
  5. Pick a layout pattern such as 2B-1. Click a button on screen to change just that button.
  6. Closing the window does not quit the app; it keeps running in the notification area. Right-click the icon to open settings, pause or quit.
The app itself is in Japanese; the labels in these pictures are translated for reference.

Per-game settings

  • When a game starts in MAME, ShotPanel reads the ROM name from the window title. Games without their own settings use the common settings; one button creates settings just for that game.
  • You can copy settings from another game.

Requirements and notes

  • Windows 10/11 (64-bit) and the Microsoft Edge WebView2 Runtime (included with Windows 11 and updated Windows 10).
  • Features handled inside a stick, such as its own turbo switch, cannot be read. Analog values (how far a stick is pushed) are not sent; sticks work only as up/down/left/right.
  • MAMEUI writes its settings back when it closes, so ShotPanel will not change them while MAMEUI is open. Avoid assigning inputs by hand or using "reset to default" in MAMEUI's input settings; they get out of step with ShotPanel.
  • Turbo is not perfectly synced to MAME's frames. If a game misses shots at 30 per second, lower it to 20 or 15.
